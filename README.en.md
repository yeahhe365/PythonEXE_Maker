## Overview

A desktop tool for converting Python scripts into standalone EXE files with drag-and-drop, batch conversion, custom icons, and version metadata.

## Features

- Convert Python scripts to EXE files.
- Drag-and-drop and batch conversion.
- Custom icons and version metadata.
- Task management and log viewing.

## Quick Start

- Prepare a Python environment.
- Enter `PythonEXE_Maker`.
- Install dependencies required by the source, such as PyQt and PyInstaller.
- Run `python main.py`.

## Configuration

- Select scripts, icons, version metadata, and output directory in the UI.

- Python
